# Projet PHP de démonstration

Ce projet contient des **failles pédagogiques intentionnelles** (SQLi, XSS, IDOR, upload, sessions faibles, secrets en clair, dépendances obsolètes). Il n'est pas exécutable en l'état (pas de base de données fournie) et ne doit jamais être déployé.

Il est utilisé par Cybbig pour démontrer le scanner statique et le pipeline de résultats. Les valeurs de secrets sont fictives.
